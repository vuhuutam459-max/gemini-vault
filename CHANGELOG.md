# Changelog

## Unreleased — Rebrand to **Chatrove**

**EN:** The project has been renamed from *Gemini Vault* to **Chatrove** to reflect
that it is a vendor-neutral, local archive and search tool for AI chats (Gemini,
ChatGPT, Claude) and to avoid tying the product name to a single provider's
trademark. Only user-facing names and paths changed; on-disk data is untouched —
the database file stays `gemini_vault.db`, so existing archives keep working with
no migration.

**RU:** Проект переименован из *Gemini Vault* в **Chatrove** — чтобы имя было
нейтральным к вендорам (продукт хранит и ищет чаты Gemini, ChatGPT, Claude) и не
было завязано на товарный знак одного поставщика. Изменились только видимые
названия и пути; данные на диске не тронуты — файл БД остаётся `gemini_vault.db`,
поэтому существующие архивы продолжают работать без миграции.
